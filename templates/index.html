The two output folders

Step 2 writes exactly one small JSON file per student into each folder. Marks never appear in folder 1 and answers never appear in folder 2.

Folder 1 - what the student wrote

  }
}
Folder 2 - what the teacher gave (labels)
{{ marks_dir }} 
{
  "roll_number": "s1",
  "marks": { "1": 7, "2": 5, "3": 2, "4": 3 }
}

The AI chooses the training papers from folder 1 only; the labels for those papers come from folder 2. All other papers are tested after fine-tuning and compared with their folder-2 marks.
